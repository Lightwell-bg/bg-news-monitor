# BG News Monitor

MVP-сервис для отбора важных новостей Болгарии для русскоязычной аудитории. Он находит новые материалы, исключает дубликаты, готовит русский черновик и отправляет кандидата администратору в Telegram.

Публикация в канал возможна только после кнопки «✅ Опубликовать». AI не публикует сообщения и не заменяет проверку прав и статуса кодом.

## Статус

Сейчас создана только архитектура, конфигурационные контракты и задача первого вертикального сценария. Прикладной код, сетевые операции, Telegram и AI-вызовы отсутствуют.

## Стек после реализации

- Python 3.12, aiogram 3, httpx, selectolax, pydantic-settings;
- SQLAlchemy 2, aiosqlite, SQLite, APScheduler;
- OpenRouter HTTP API и pytest.

## Безопасность

- Только `TELEGRAM_ADMIN_IDS` управляют кнопками.
- Уникальность: нормализованный URL и хеш содержимого.
- Невалидный AI-ответ, придуманные факты и полный текст чужой статьи не публикуются.
- Ссылка на исходный материал обязательна.
