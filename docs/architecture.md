# Архитектура BG News Monitor

## Цель и границы MVP

Сервис обрабатывает настроенные источники и отправляет администратору кандидаты для Telegram-канала. MVP использует SQLite и не публикует ничего без явного решения администратора. Первый вертикальный сценарий ограничен главной страницей Flagman; тесты используют только локальные fixtures и fake-клиенты.

## Поток

```text
Scheduler -> source adapter -> article fetcher -> URL/content deduplication
-> deterministic filter -> AI assessor/drafter (Pydantic JSON)
-> private admin card -> authorized atomic callback -> channel publisher
```

AI формирует структурированный кандидат (оценку, объяснение, русский заголовок и краткий черновик) и не имеет возможности Telegram-публикации. Публикатор вызывается кодом только после проверки администратора и перехода в `APPROVED`.

## Будущие модули

| Область | Ответственность |
| --- | --- |
| `config` | Settings и `sources.yaml`, без вывода секретов. |
| `sources` | Контракты и адаптеры списков/статей. |
| `normalization` | URL и хеш нормализованного содержимого. |
| `filters` | Детерминированные правила. |
| `ai` | OpenRouter HTTP и строгая Pydantic-схема. |
| `storage` | SQLAlchemy, SQLite, статусы и атомарные переходы. |
| `telegram` | Карточки, callback-права и публикация. |
| `scheduler` | Интервалы источников. |

## Данные и уникальность

Новость хранит источник, исходный и нормализованный URL, время публикации, оригинальный заголовок, хеш содержимого, статус, оценку, русский черновик и Telegram-идентификаторы. Для `normalized_url` и `content_hash` нужны уникальные ограничения; совпадение любого из них означает `DUPLICATE`.

## Статусы

| Статус | Значение |
| --- | --- |
| `DISCOVERED` | Ссылка найдена. |
| `FETCHED` | Получены метаданные и контекст. |
| `DUPLICATE` | Совпали URL или хеш. |
| `REJECTED_BY_FILTER` | Отклонено правилами. |
| `CANDIDATE` | AI-результат валиден. |
| `AWAITING_APPROVAL` | Карточка отправлена. |
| `REJECTED_BY_ADMIN` | Отклонено администратором. |
| `APPROVED` | Код может публиковать. |
| `PUBLISHED` | Единственный пост опубликован. |
| `PUBLICATION_FAILED` | Публикация завершилась ошибкой. |

Допустимый путь: `DISCOVERED -> FETCHED -> DUPLICATE | REJECTED_BY_FILTER | CANDIDATE -> AWAITING_APPROVAL -> REJECTED_BY_ADMIN | APPROVED -> PUBLISHED | PUBLICATION_FAILED`. Callback должен быть идемпотентным.

## Telegram и качество

Карточка включает источник, время, оценку 0–100, объяснение, оригинальный и русский заголовки, черновик и ссылку. Кнопки: «✅ Опубликовать», «❌ Отклонить», «🔄 Перегенерировать», «🔗 Открыть источник». Управляющие действия доступны только числовым ID из `TELEGRAM_ADMIN_IDS`; `TELEGRAM_ADMIN_ID` поддерживается как одиночная обратная совместимость. Невалидный AI JSON, оценка вне диапазона или неполные поля не создают карточку и публикацию. Русский текст не добавляет фактов, полный текст статьи не копируется, ссылка обязательна в посте. В логах запрещены токены, ключи, авторизационные заголовки, `.env` и полный текст статей.
