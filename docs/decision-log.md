# Журнал решений

## 2026-09-10 — SQLite и модерация человеком

- MVP использует SQLAlchemy 2, aiosqlite и SQLite.
- Дубликат определяется нормализованным URL или хешем содержимого.
- AI создаёт только Pydantic-валидируемую оценку и черновик.
- Код публикует только после авторизованного решения из `TELEGRAM_ADMIN_IDS` и перехода в `APPROVED`.
- Ссылка на источник обязательна; полный текст чужой статьи не копируется.
